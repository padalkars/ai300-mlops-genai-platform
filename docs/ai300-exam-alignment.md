# AI300 exam topic alignment

## Topic mapping to project work

### Azure Machine Learning basics
- Workspace setup and resource understanding
- Compute targets and environment configuration
- Dataset versioning and data ingestion

### Machine learning lifecycle
- Exploratory data analysis
- Data preparation and feature engineering
- Model training and evaluation
- Model registration and deployment

### MLOps automation
- Pipelines for repeatable execution
- Reusable training components
- CI/CD for model delivery

### Monitoring and governance
- Drift detection
- Model performance checks
- Feedback and retraining loops

### Generative AI / GenAIOps
- RAG or Foundation Model integration
- Prompt evaluation
- Tracing and observability

## Practical project sequence

1. Start with data analysis and baseline model training.
2. Add experiment tracking.
3. Create a reusable training pipeline.
4. Register the model.
5. Deploy to managed inference endpoint.
6. Add GitHub Actions and Bicep for automation.
7. Add monitoring and retraining logic.
8. Extend with GenAI evaluation and tracing.

## Why this alignment matters

The exam typically rewards understanding of the complete ML operational lifecycle rather than isolated coding tasks. This project deliberately follows that lifecycle so the implementation and the study notes reinforce the same concepts.
